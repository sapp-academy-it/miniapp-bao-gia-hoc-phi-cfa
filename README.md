# Báo giá học phí CFA

Mini app nội bộ cho tư vấn viên SAPP lập báo giá học phí CFA và xem lịch khai giảng.

- Dữ liệu lớp và học phí lấy từ OPS API sau khi đăng nhập.
- Môi trường hiện tại: UAT.
- Chính sách ưu đãi chưa có trong API được cấu hình và lưu trên trình duyệt.
- Trang GitHub Pages là công khai; dữ liệu thật chỉ hiển thị sau khi đăng nhập OPS.
